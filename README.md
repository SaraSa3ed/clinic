# نظام إدارة غسيل السيارات - Wash Wheels Cloud Suite

## نظرة عامة
نظام متكامل لإدارة خدمات غسيل السيارات يشمل إدارة الفروع، المخزون، المبيعات، العملاء، والموظفين.

## المميزات الرئيسية

### 🏢 إدارة الفروع
- إدارة متعددة الفروع
- تتبع الأداء لكل فرع
- إعدادات مخصصة لكل فرع

### 📦 إدارة المخزون
- تتبع المخزون في الوقت الفعلي
- إدارة الموردين والشركات المصنعة
- تنبيهات المخزون المنخفض
- تقارير المخزون الشاملة

### 💰 نظام نقاط البيع (POS)
- واجهة بيع سريعة وسهلة
- إدارة المدفوعات المتعددة
- طباعة الفواتير
- تقارير المبيعات المفصلة

### 👥 إدارة العملاء (CRM)
- قاعدة بيانات العملاء الشاملة
- إدارة المركبات
- نظام الولاء والنقاط
- الحملات التسويقية

### 🚗 الخدمات المتنقلة
- إدارة الحجوزات المتنقلة
- تتبع الفرق المتنقلة
- إدارة الجودة
- تطبيق المريض

### 👨‍💼 إدارة الموارد البشرية (HCM)
- إدارة الموظفين
- الرواتب والحضور
- الأداء والتقييم
- التدريب والتطوير

### 📊 التقارير والتحليلات
- لوحات تحكم تفاعلية
- تقارير مالية مفصلة
- تحليلات الأداء
- مؤشرات الأداء الرئيسية

## التثبيت والتشغيل

### المتطلبات
- Node.js 18+ 
- npm أو yarn

### خطوات التثبيت

1. **استنساخ المشروع**
```bash
git clone <repository-url>
cd wash-wheels-cloud-suite
```

2. **تثبيت التبعيات**
```bash
npm install
```

3. **تشغيل التطبيق**
```bash
npm run dev
```

4. **فتح المتصفح**
```
http://localhost:8081
```

### ✅ ما يعمل حالياً

## البيانات الوهمية

عند عدم توفر الخادم الخلفي، سيعرض النظام:
- ✅ قائمة الفئات (خدمات الغسيل، التلميع، الصيانة، منتجات العناية)
- ✅ قائمة الفروع (الفرع الرئيسي، فرع الشمال، فرع الجنوب)
- ✅ قائمة الشركات المصنعة (تويوتا، هوندا، نيسان)
- ✅ قائمة الموردين (مورد المواد الأساسية، مورد الأدوات، مورد الكيماويات)
- ✅ قائمة المستودعات (المستودع الرئيسي، مستودع المواد الكيميائية، مستودع الأدوات)

## هيكل المشروع

```
src/
├── components/          # المكونات القابلة لإعادة الاستخدام
│   ├── ui/            # مكونات واجهة المستخدم الأساسية
│   ├── Inventory/     # مكونات المخزون
│   ├── POS/          # مكونات نقاط البيع
│   ├── CRM/          # مكونات إدارة العملاء
│   └── HCM/          # مكونات إدارة الموارد البشرية
├── pages/             # صفحات التطبيق
│   ├── Dashboard/     # لوحة التحكم الرئيسية
│   ├── Inventory/     # صفحات المخزون
│   ├── POS/          # صفحات نقاط البيع
│   ├── CRM/          # صفحات إدارة العملاء
│   └── HCM/          # صفحات إدارة الموارد البشرية
├── services/          # خدمات API
├── hooks/             # React Hooks المخصصة
├── store/             # إدارة الحالة (Redux)
├── types/             # تعريفات TypeScript
└── utils/             # أدوات مساعدة
```

## التقنيات المستخدمة

- **Frontend**: React 18, TypeScript, Vite
- **UI Framework**: Tailwind CSS, shadcn/ui
- **State Management**: Redux Toolkit, RTK Query
- **Routing**: React Router DOM
- **Forms**: React Hook Form, Zod
- **Charts**: Recharts
- **Icons**: Lucide React
